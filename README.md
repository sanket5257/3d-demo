# 3d-demo

Two real-time 3D showcase pages built with Next.js, three.js and GSAP.

| Route | What it is |
| --- | --- |
| `/car` | **Neunelf** — a Blender-built two-door concept car you walk around as you scroll (camera shots, live dimensions, airflow, night mode, rendered film, paint picker). |
| `/iustitia` | **Iustitia** — a digital exhibition of a marble Lady Justice: guided camera tour with live annotations, physics-driven scales, a breathing hem, four switchable materials and a drag-to-turn turntable. |

`/` redirects to `/iustitia`.

## Run

```bash
npm install
npm run dev     # http://localhost:3000
npm run build && npm start
```
