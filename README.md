# 3d-demo

Two real-time 3D showcase pages built with Next.js, three.js and GSAP.

| Route | What it is |
| --- | --- |
| `/car` | **Neunelf** — a Blender-built two-door concept car you walk around as you scroll (camera shots, live dimensions, airflow, night mode, rendered film, paint picker). |
| `/lady-justice` | A marble **Lady Justice** prologue (sculpted, cleaned up and rigged in Blender) leading into a demo landing page. Personalise with `?name=`. |

`/` redirects to `/lady-justice`.

## Run

```bash
npm install
npm run dev     # http://localhost:3000
npm run build && npm start
```
